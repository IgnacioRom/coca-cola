# Juegos por el planeta

Este proyecto contiene dos juegos web sobre reciclaje y sustentabilidad.

## Juegos

- **Misión Reciclaje:** elegí el tacho correcto para cada residuo.
- **Ruleta Sustentable:** respondé preguntas y sumá puntos.

## Cómo usarlo

1. Abrí el archivo `index.html` en un navegador.
2. Elegí uno de los dos juegos.
3. Seguí las instrucciones que aparecen en pantalla.

También podés iniciar un servidor local desde la carpeta del proyecto:

```bash
python -m http.server 8000
```

Después abrí [http://localhost:8000](http://localhost:8000) en el navegador.
